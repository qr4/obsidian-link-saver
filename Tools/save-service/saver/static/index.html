    YouTube cookies

    How to export

    Log in to YouTube in a private window, export with a cookies.txt extension (Netscape format) or Cookie-Editor (JSON), then close the window - YouTube rotates the cookies of sessions that stay open. Stored in /config (mode 600); values are never shown.

    Browse
    How this works

    Videos and full git clones are stored outside the vault and served by this service. The vault keeps what's small and searchable: each repo's README (whole gists), every transcript and subtitle file, and an .offloaded marker with the link. Notes link to a watch page (with subtitles, ?t= for a start time) or the repo's file listing.
